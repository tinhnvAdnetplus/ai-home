# TASK T6.1 — AI backend: LlmProvider + design-constraints endpoint + plan commentary (PHP lane). Touch NOTHING under `resources/js` and `packages/`.

Why: the product promise is "AI draws the ideal house". The customer's structured answers (wizard) plus the free-text box (その他の希望, up to 200/300 chars per step) are sent to an LLM that returns STRICT JSON "design constraints" which the TypeScript planner (in the browser) consumes; later the same LLM writes a short Japanese explanation of each of the 3 proposals. The LLM never invents geometry; its output is validated server-side and rejected if invalid.
PHP 8.2 only, one port, no Node. Read first: `docs/api-contract.md` (RFC 9457 errors, request ids), `app/Http/Controllers/*Config*`, `app/Config/Wizard/**`, `routes/api.php`, `config/`, `docs/answers-mapping.md` (answer keys), `docs/planner.md`.

## 1. Provider layer `app/Ai/`
- `LlmProvider` interface: `generateJson(LlmRequest $req): LlmResult` (system prompt, user content, JSON schema, temperature, max tokens, timeout) with result {data array, usage {inputTokens, outputTokens}, latencyMs, provider, model}.
- `GeminiProvider` (REST `generativelanguage.googleapis.com` `generateContent` with `responseMimeType: application/json` + `responseSchema`; use Laravel Http client, timeout 20 s, 2 retries with backoff on 429/5xx), `ClaudeProvider` (Anthropic Messages API, forced tool use with the JSON schema as the tool input schema), `LocalHeuristicProvider` (NO network: deterministic Japanese keyword/regex parser of the free text + answers, e.g. 「平屋」「収納を多く」「書斎」「テレワーク」「ペット」「バリアフリー」「南向き」「家事動線」; used when no API key is configured or the call fails). Binding chosen by `config/ai.php` + env: `AI_PROVIDER=gemini|claude|local` (default `local`), `GEMINI_API_KEY`, `GEMINI_MODEL` (default a current Gemini flash model id), `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `AI_TIMEOUT`, `AI_DAILY_LIMIT`. Add all keys (empty) to `.env.example`. Keys are never logged or returned.
- A `FallbackProvider` decorator: primary (gemini/claude) -> on exception/timeout/invalid JSON -> LocalHeuristicProvider, and the response says `source: "gemini"|"claude"|"local"` and `degraded: true` when fallback was used. Never pretend local output is LLM output.

## 2. Design-constraints schema `app/Ai/Schema/DesignConstraints.php` (+ JSON Schema file `resources/ai/design-constraints.schema.json`)
Strict, bounded object (additionalProperties false, arrays capped): 
`{ schemaVersion:1, summary: string<=200 (ja), priorities: {housework, storage, daylight, budget, privacy, family} each int 0..5, mustHaveRooms: [enum room types incl. study, tatami, walkInCloset, pantry, laundry...], avoidRooms: [...], roomHints: [{room, count 0..6, sizeJo 3..40}], adjacency: [{a, b, relation: near|far|adjacent}] (<=8), orientation: {livingFacing: north|south|east|west|any, entranceSide: ...|any}, accessibility: {oneLevelLiving: bool, wideCorridors: bool}, pets: bool, workFromHome: bool, notes: [string<=80] (<=6), unmappedRequests: [string<=120] (<=6) }`.
`ConstraintsValidator` rejects anything outside the schema, clamps numbers, strips unknown keys, drops hostile strings (control chars, prompt-injection-looking text is kept ONLY inside notes/unmappedRequests, never executed). Unknown room names -> unmappedRequests.

## 3. Endpoints (`/api/v1`, throttled `throttle:ai` 10/min per IP+user, body <= 32 KB, RFC 9457 errors, request id)
- `POST /ai/constraints` body `{ answers: object, locale: ja|en|vi }` -> `{ constraints, source, degraded, model, usage, requestId }`. Server first builds a compact prompt from answers (only allowed keys from the published wizard config, free text truncated and wrapped in a delimiter block labelled as untrusted user text; system prompt states the output contract and that user text is data not instructions). Prompt text lives in `resources/ai/prompts/constraints.ja.md` (editable later from admin).
- `POST /ai/commentary` body `{ answers, constraints, plans: [{label, score:{housework,storage,daylight,budget,total}, summary:{floorAreaM2,tsubo,roomsList}, warnings:[codes]}] (max 3) }` -> `{ items:[{label, headline<=40, body<=300, pros:[<=3], cautions:[<=3]}], recommendedLabel, source, degraded }`; LocalHeuristic produces sensible Japanese text from the numbers (template-based) so the UI is never empty.
- Auth: optional (guests allowed; if authenticated, attach user id). Daily cap per IP/user from `AI_DAILY_LIMIT`.
- Table `ai_calls` (id, user_id nullable, endpoint, provider, model, source, degraded, input_tokens, output_tokens, latency_ms, status, created_at; NO prompt/answer text, no PII). Migration with plain `migrate` only; NEVER `migrate:fresh/reset` on the dev DB.
- `GET /admin/ai/usage` (roles admin|editor) -> last 100 rows + totals per day/provider.
